# AI Context Documents

- `construction-glossary.md` — 建設業界の用語集
- `bim-workflow.md` — BIM 業務フローの概要
- `building-code-basics.md` — 建築基準法の基本（建ぺい率・容積率・避難経路）

これらは開発が進むにつれて追加していきます。
